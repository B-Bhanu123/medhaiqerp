# MedhaIQ ERP - Administrative & User Manual

Welcome to the MedhaIQ Education ERP System. This manual provides instructions for administrators, deans, finance officers, faculty, and students.

## Quick Navigation

1. **Dashboard Navigation**:
   - Use the left sidebar to navigate between Executive Analytics, Student SIS, Academics, Finance, HR, Library, Hostel, Transport, and Noticeboard.

2. **Registering Students**:
   - Navigate to **Student SIS**.
   - Click **+ Register New Student**.
   - Fill in demographic details, academic program assignment, and guardian contacts.
   - Click **Save Admission**.

3. **Processing Fee Payments**:
   - Navigate to **Finance & Fees**.
   - Search for student invoice by admission number or invoice ID.
   - Click **Record Payment**, select payment gateway/cash method, and issue receipt.
